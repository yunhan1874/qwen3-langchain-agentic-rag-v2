## 日志和回退

服务器当前日志：`/tmp/qwen3-vllm-service.log`（推理服务）和 `/tmp/qwen3-rag-web.log`（前端）。服务以独立后台进程运行；如服务器重启，需要依照 README 重新启动推理服务和前端。
